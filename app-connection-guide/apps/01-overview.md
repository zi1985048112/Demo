# 概述

> 摘自《应用连接文档（AI 员工接入各应用指南）》第 1 章（完整版见 [../README.md](../README.md)）。状态图例：✅ 已实测可用；⚠️ 部分可用 / 有已知问题；❌ 当前不可用；⬜ 未测试。

## 每个连接能做什么

| 应用 | 接入方式 | 状态 | 接入后能做什么（简要） |
|---|---|---|---|
| **IM 聊天渠道** |  |  |  |
| Microsoft Teams | 渠道组件（Azure 机器人 + Teams 应用包，需公网 HTTPS 回调） | ✅ | 私聊、群聊、Team 频道 @ 对话，主动发消息、收发图片；能收文件 / 音视频（开通转写后可转文字）；❌ 不能发图片以外的文件、不支持语音消息 |
| Slack | 渠道组件（Socket Mode，不需公网） | ✅ | 私聊、频道 @ 对话，线程回复、Markdown；私有频道 / 文件收发未测 |
| Discord | 渠道组件（Gateway 长连接，不需公网） | ✅ | 私聊、服务器频道 @ 对话；附件、回复 / 编辑 / 表情回应等事件 |
| Lark（国际版） | 渠道组件（Lark 自建应用，长连接） | ✅ | 私聊、群聊 @ 对话，收发图片；可授权办公能力（文档 / 表格 / 日历等） |
| 飞书（国内） | 渠道组件（飞书自建应用，长连接） | ⚠️ | 私聊已验证；群聊、办公能力未测；须用飞书企业账号 |
| 企业微信 | 渠道组件（智能机器人 API 模式 + 长连接） | ⚠️ | 私聊已验证；群聊未测，群里只收得到 @ 机器人的文字 / 图文 |
| 钉钉 | 渠道组件（Stream 模式） | ⚠️ | 私聊已验证；群聊未测；可读取用户发来的文档内容 |
| WeChat（个人微信） | 渠道组件（微信官方机器人接口，扫码登录） | ✅ | 一对一私聊、主动推送（有时间窗口限制）；❌ 不支持群聊 |
| WhatsApp | 渠道组件（WhatsApp Web 关联设备扫码，非官方商业 API） | ✅ | owner 自聊、白名单联系人私聊、群聊 @、引用回复 |
| Telegram | 渠道组件（@BotFather 机器人，长轮询） | ✅ | 私聊、群消息接收 / 监控；群内 @ 回复未单独测 |
| Zalo | 渠道组件（Zalo 官方 Bot 平台，轮询） | ✅ | 私聊、群聊 @；❌ 语音消息无法转文字 |
| LINE | LINE 官方账号 + Messaging API（工作台「对话入口」填两个密钥） | ✅ | 私聊、群聊 @、图片、@所有人、引用回复；群里暂无 mention / smart 开关；慢回复和主动推送计入 LINE 月额度 |
| **邮箱** |  |  |  |
| Gmail | 连接器（OAuth）或 应用专用密码 + IMAP/SMTP（推荐） | ✅ | 读信、搜索、发信、草稿、星标 / 标签（连接器）、7×24 回复监控 |
| QQ 邮箱 | 授权码 + IMAP/SMTP | ✅ | 收信监控推送、读信、发信 |
| Outlook | 连接器（OAuth） | ✅ | 读信、收信、发信；日历 / 联系人未测 |
| 阿里邮箱 | 暂无专用连接器 | ⬜ | 未测（可走通用「邮箱 (MCP)」，需要时再测） |
| **应用连接器** |  |  |  |
| GitHub | 连接器（OAuth） | ✅ | 查看账号 / 仓库，配合 git 拉取公开仓库运行、部署；建 Issue / PR 等写操作未测 |
| LinkedIn | 连接器（OAuth） | ⚠️ | 读个人资料、发帖、删帖、查点赞；❌ 读帖子 / 评论暂不支持 |
| Google Analytics | 连接器（OAuth） | ⚠️ | 查看 GA 账号、受众；❌ 暂不能查访问量报表 |
| Google Drive | 连接器（OAuth） | ✅ | 搜索、读写文件、整理文件夹、共享、评论 |
| Google Search Console | 连接器（OAuth） | ✅ | 搜索数据、站点地图查询 / 提交；❌「检查网址」暂不可用 |
| Facebook | 连接器（OAuth） | ❌ | 目前只能读取主页信息、帖子、照片；不能发帖、看数据洞察、看私信 |
| Instagram | 连接器（OAuth） | ✅ | 账号 / 帖子数据、发帖、读 / 回复评论；私信未测；不能删帖、改帖 |
| Notion | 连接器（OAuth） | ✅ | 搜索、读写页面、数据库增改；❌ 评论暂不可用 |
| Linear | 连接器（OAuth） | ✅ | 查 / 建 / 改任务、标签、评论，删除任务 |
| Vercel | 连接器（API 令牌） | ✅ | 项目管理、发布网页、部署 / 日志、环境变量、域名；购买域名等高风险动作未测 |
| Zoho | 连接器（OAuth，Zoho CRM） | ✅ | 线索 / 联系人 / 客户 / 商机读写、线索转化、联系人角色；❌ 不能删除记录；Books / Desk / Inventory / Mail 暂无可用功能 |
| Amazon SP-API | 暂无官方连接器 | ❌ | 暂不支持管理自己店铺的订单 / 库存 / Listing；可选市场数据类替代（见下方明细，未测） |

## 对比总表（首批 6 个应用）

| 应用 | 接入方式 | 支持场景 | 访问控制模式 | 是否需要公网回调 | 实测情况 |
|---|---|---|---|---|---|
| Microsoft Teams | 渠道组件 + Azure 机器人注册 + Teams 应用包（manifest） | 私聊 / 群聊 / Team 频道 | 私聊：owner / allowlist / open / pairing / disabled；群聊：disabled / allowlist / open + 群内成员白名单；mention / smart | **需要**（HTTPS 消息接收地址） | ✅ 私聊、群聊、Team 频道（mention 模式）已验证，私聊可并入统一上下文；收图片 / 文件 / 音视频 ✅，发图片 ✅；发其他文件 ❌、语音消息 ❌（平台限制） |
| Slack | 渠道组件 + Slack App（Socket Mode） | 私聊 / 公开频道 / 私有频道（线程） | 私聊：owner / allowlist / open；频道：disabled / allowlist / open；mention / smart | **不需要**（Socket Mode）；webhook 模式才需要 | ✅ 私聊、频道 @ 已验证，私聊可并入统一上下文 |
| Discord | 渠道组件 + Discord Bot（Gateway 长连接） | 私聊 / 服务器频道 / 子线程 | 私聊：owner / allowlist / open / pairing；服务器：disabled / allowlist / open + 频道成员白名单；mention / smart | **不需要** | ✅ 私聊、服务器频道 @ 已验证，私聊可并入统一上下文 |
| Gmail | ① OpenMax 连接器（OAuth 授权）② 应用专用密码 + IMAP/SMTP | 邮箱（非聊天） | 连接器：由平台授权控制；IMAP：密码只存机器人本机 | 不需要 | ✅ 两种方式均已验证；推荐 IMAP/SMTP（更稳定），连接器作补充 |
| GitHub | OpenMax 连接器（OAuth 授权，direct 模式） | 代码仓库（非聊天） | 由平台授权控制 | 不需要 | ✅ 授权、浏览仓库、拉取部署已验证；写操作未测 |
| LINE | 官方账号（OA）+ Messaging API；OpenMax 工作台「对话入口」填两个密钥 | 私聊 / 群聊 | 私聊：owner / allowlist / open / pairing / disabled；群聊：disabled / allowlist / open + 群内成员白名单；**暂无 mention / smart 开关** | **需要**（Webhook，由平台提供） | ✅ 私聊 + 群聊已验证；暂未验证并入统一上下文 |

## 各应用测试结果明细（截至 2026-10-16）

图例：✅ 已实测可用　⚠️ 部分可用 / 有已知问题　❌ 当前不可用　⬜ 未测试。各项详情见对应章节的「测试清单」和「踩坑记录与解决办法」。

**小结**：12 个 IM 渠道均已接入并验证私聊（飞书、企业微信、钉钉的群聊未测；个人微信只支持私聊）。邮箱：Gmail、QQ 邮箱、Outlook 可用，阿里邮箱未测。应用连接器：Google Drive、Linear、Vercel（实测 23/44 个动作）、Zoho CRM（6/6）、Instagram（私信未测）、Notion（评论除外）、GitHub（读操作）可用；Google Search Console 6 个动作中 5 个可用；LinkedIn、Google Analytics 部分可用；Facebook 目前只能读取；Amazon SP-API 暂无官方连接器。
