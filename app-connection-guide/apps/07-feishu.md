# 飞书（国内）

> 摘自《应用连接文档（AI 员工接入各应用指南）》第 7 章（完整版见 [../README.md](../README.md)）。状态图例：✅ 已实测可用；⚠️ 部分可用 / 有已知问题；❌ 当前不可用；⬜ 未测试。

飞书是字节跳动的企业协作平台（国内版），聊天、云文档、多维表格、日历、视频会议、审批一体，类似「钉钉 / 企业微信」；海外版叫 Lark（见上一章），两者账号、应用、组件都分开。通过机器人端的 **飞书渠道组件**接入，使用 **长连接（WebSocket）模式**，不需要公网地址（也支持事件回调模式）；也可由 OpenMax 平台托管连接。实测：**私聊通过**；群聊、办公能力未测，暂未验证并入统一上下文。

## 能做什么

- 私聊：owner 与机器人一对一对话。
- 群聊：@ 机器人触发回复；可登记多个群，分别设置 mention / smart 模式和成员白名单（与 Lark 组件一致）。
- 收发文字、图片、文件；回复可用 Markdown 卡片格式。
- 内置飞书办公能力（文档、表格、多维表格、日历、任务、邮箱等），需 owner 本人授权后才能用（未实测）。
- ⚠️ **当前限制**：群聊、图片 / 文件收发、办公能力尚未实测；必须使用飞书**企业**账号——用豆包账号登录的飞书是个人空间，无法创建自建应用（替代办法见踩坑第 2 条）。

## 前置条件 / 所需权限 / 账号

| 项目 | 说明 |
|---|---|
| 飞书**企业**账号（组织租户） | 需要能进飞书开发者后台创建并发布自建应用。**用豆包账号登录的飞书是个人空间，没有管理后台，连不上 agent**（见踩坑） |
| 飞书自建应用 | 在 open.feishu.cn/app 创建，开启「机器人」能力，订阅「接收消息」事件（im.message.receive_v1） |
| 凭据 | App ID + App Secret；长连接模式**不需要** Verification Token 和回调地址，回调模式才需要 |
| 网络 | 长连接不需要公网地址（推荐）；回调模式需公网 HTTPS 地址 |
| 应用可用范围 | 决定谁能找到、打开机器人（两层控制的第一层，见「通用概念 → 私聊访问控制」） |
| 访问控制 | 推荐：私聊 owner、群聊 allowlist（私聊 dmPolicy、群聊 groupPolicy、mention / smart 的含义见「通用概念」） |

## 详细接入步骤（私聊已验证；建应用步骤按组件说明整理）

1. 飞书开发者后台（open.feishu.cn/app）→ 创建企业自建应用 → 填写名称、头像。
2. 添加应用能力 → **机器人**。
3. 事件与回调 → 订阅方式选 **长连接** → 添加事件「接收消息」（im.message.receive_v1）。长连接模式无需填写请求地址和 Verification Token。
4. 开通消息类权限，创建版本、设置可用范围并发布（官方流程，未实测）。
5. 把 App ID / App Secret 交给机器人端完成配置（由 OpenMax 平台托管连接时，由平台完成配置和连接）。
6. **由 owner 本人**第一个私聊机器人 → 自动绑定 owner（实测：首条「你好」即自动绑定）→ 请 owner 确认是本人。
7. 群聊：把机器人拉进群 → 管理端登记该群 → 群里 @ 机器人测试（未实测）。

## 踩坑记录与解决办法

- **owner 私聊没反应，消息被当成陌生人拒绝**<br>原因：owner 绑定里存的是旧应用下的用户 open_id——飞书的 open_id 按应用区分，换了应用后同一个人的 open_id 也会变；加上豆包登录的租户没有 user_id，匹配不上，被 dmPolicy=owner 拒绝。<br>解决：owner 确认后清空旧绑定，平台重新连接机器人，owner 再发第一条私聊重新自动绑定。
- **豆包账号登录飞书连不上 agent**（报错 21001）<br>原因：豆包登录进的是个人空间，没有管理后台，无法创建 / 发布自建应用。<br>解决：① 新建飞书企业账号（可跳过企业认证）后再建机器人；要把机器人加进外部群，需个人实名认证后勾选「允许机器人被添加到外部群中使用」，或把同事拉进该组织、在内部群里使用；② 改用 OpenMax Workspace 群聊与 agent 对话（手机浏览器登录后可添加到桌面）。
- **同一个飞书应用不要同时接两个 agent / 工具**：同一应用的消息会被分流，各工具各用一个应用。
- **飞书与 Lark 是两个组件**：国内租户用飞书组件，海外 Lark 用 Lark 组件；两者同装时办公能力授权分开保存，别混用。

## 日常运维 / 注意事项

- 换了飞书应用（或平台重新开通）后，owner 需重新发第一条私聊完成绑定，并确认是本人。
- App Secret 泄露时在开发者后台重置，并更新到机器人端。
- 新群建议登记为 mention 模式；机器人在群里的回复所有成员可见，隐私内容请走私聊。
